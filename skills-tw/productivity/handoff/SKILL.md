---
name: handoff
description: 將目前的對話彙整成交接文件，供其他 agent 接手使用。
argument-hint: "下一次工作階段的用途為何？"
disable-model-invocation: true
---

撰寫一份交接文件，彙整目前的對話內容，讓新的 agent 能夠接續作業。請儲存至使用者作業系統的暫存目錄，而非目前的工作區。

文件中須包含「建議技能」章節，列出下一位 agent 應該呼叫 Skill 工具的技能名稱。

避免重複已存在於其他成果物中的內容（例如規格文件、計畫、ADR、issue、commit、diff）。改以路徑或 URL 的方式引用即可。

請將任何敏感資訊（如 API 金鑰、密碼或個人識別資訊）進行遮蔽處理。

若使用者有傳入參數，請將其視為下一次工作階段的重點說明，並據此調整文件內容。
