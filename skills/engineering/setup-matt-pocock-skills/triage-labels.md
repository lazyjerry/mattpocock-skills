# 分流標籤

這些技能是以五種標準分流角色（canonical triage roles）來描述的。本檔案將這些角色對應到本儲存庫議題追蹤系統中實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 我們追蹤系統中的標籤 | 意義                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需要評估此議題  |
| `needs-info`               | `needs-info`         | 等待回報者提供更多資訊 |
| `ready-for-agent`          | `ready-for-agent`    | 規格已完整，可交由 AFK agent 處理  |
| `ready-for-human`          | `ready-for-human`    | 需要人工實作 |
| `wontfix`                  | `wontfix`            | 不會處理 |

當某項技能提及某個角色時（例如「套用 AFK-ready 分流標籤」），請使用本表中對應的標籤字串。

請編輯右側欄位，改成你實際使用的詞彙。
