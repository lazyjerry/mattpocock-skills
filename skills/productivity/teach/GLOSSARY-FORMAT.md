# GLOSSARY.md 格式

`GLOSSARY.md` 是這個教學工作區中的標準用語。所有的說明文件、練習題與學習記錄都應該遵循其中的術語。建立這份文件本身就是學習的一部分：把一個概念濃縮成精簡的定義，正是使用者理解這個概念的證明。

## 結構

```md
# {主題} 詞彙表

{對這份詞彙表所涵蓋主題的一到兩句描述。}

## 詞彙

**Hypertrophy**:
在反覆的訓練中，由機械張力與代謝壓力所驅動的肌肉生長。
_避免使用_：Bulking, getting big

**Progressive overload**:
隨著時間，透過負重、訓練量或強度，有系統地提高對肌肉的要求。
_避免使用_：Pushing harder, levelling up

**RPE (Rate of Perceived Exertion)**:
以 1 到 10 分自評一組動作的吃力程度，10 分代表力竭，8 分代表還能再做兩下。
_避免使用_：Effort score, intensity rating
```

## 規則

- **只有在使用者理解某個詞彙後才加入詞彙表。** 詞彙表是濃縮知識的紀錄，不是給使用者拿來學習的字典。如果使用者才剛接觸到某個概念，要等到他能正確運用之後，才把它列進來。
- **要有立場。** 當同一個概念有好幾種說法時，選出最好的一個，並把其他說法列為應避免的別名。這就是語言得以濃縮的方式。
- **保持定義精簡。** 一到兩句話。定義這個詞彙「是什麼」，而不是它「做什麼」或「怎麼做」。
- **在定義中使用詞彙表自身的用語。** 一旦某個詞彙已經收錄在詞彙表中，就應該在所有地方（包括其他定義內）優先使用它。這正是讓後續複雜詞彙更容易理解的關鍵。
- **在自然形成分類時，以子標題分組**（例如 `## 解剖`、`## 課表安排`）。如果詞彙本身連貫一致，用平鋪列表也可以。
- **明確標示模糊之處。** 如果某個詞彙在更廣泛的領域中用法鬆散，就要註明釐清方式：「在這個工作區中，『set』一律指正式訓練組；熱身組會另外記錄。」
- **隨著理解加深而修訂。** 使用者在第一週寫下的定義，到了第六週可能就不正確了。要就地更新，不要留下過時的條目。
